# Astro, built by GitHub Actions

The site is generated by Astro and deployed by a GitHub Actions workflow, replacing the single hand-written index.html served straight from the main branch. Eleventy was the lighter fit for a content site and was recommended; the owner chose Astro for typed content collections and room for interactive components later. The build runs on GitHub's servers on every push to main, so no local machine has to stay on; Node is needed locally only for preview.

## Consequences

- GitHub Pages source must be "GitHub Actions", not "Deploy from a branch". With the old setting the workflow succeeds but the live site never changes.
- Astro needs Node 22.23.4 or newer (7.x); the CI workflow pins Node 24.
- Content (experience, projects, photos, videos, strands) lives in schema-validated collections, so a malformed entry fails the build instead of rendering a broken page.
- Ship zero client JavaScript by default. Islands are allowed only where interaction needs them (doodle canvas, theme toggle, lightbox, video facade).
